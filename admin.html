Pannello Master

Strumenti per gestire le schede dei personaggi

Genera una password per una scheda

Scrivi la password in chiaro che vuoi assegnare (a un personaggio, o una nuova password Master). Ottieni il codice da incollare nel file di quel personaggio.


Dove incollarlo

Apri il file .html del personaggio su GitHub (matita "Edit"), cerca questa riga vicino all'inizio dello script:

const CHAR_PASSWORD_HASH = "...";

Sostituisci il testo tra virgolette con l'hash appena generato, poi salva (Commit changes). Per cambiare invece la password Master — quella che apre tutte le schede — genera l'hash allo stesso modo, ma va sostituito nella riga const MASTER_PASSWORD_HASH = "..."; in ogni singolo file di personaggio, uno per uno: ogni scheda tiene la propria copia, non è un valore condiviso automaticamente.

Nuovo personaggio

Per una scheda nuova, genera qui la password che vuoi dargli, e passa a Claude il file di partenza insieme a quell'hash: lo inserisce lui al posto giusto nel nuovo file.
