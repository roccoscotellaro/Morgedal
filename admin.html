Pannello Master

Strumenti per gestire le schede dei personaggi

🔓 Da questo momento tutte le schede del gruppo su questo browser sono sbloccate, senza dover reinserire alcuna password.

Connessione a GitHub necessaria solo per aggiornare password/colori direttamente da qui

Serve un Personal Access Token di GitHub con permesso di scrittura su questo repository (scope repo, oppure un token "fine-grained" con permesso Contents: Read & Write sul repo Morgedal). Il token resta solo in questa scheda del browser: non viene salvato da nessuna parte, sparisce chiudendo la finestra.

⚠️ Non condividere mai questo token. Chiunque lo abbia può modificare tutti i file del repository.

Personaggi

Carica l'elenco da index.html per modificare password e colore identificativo di ciascun personaggio direttamente da qui.

Cambia la password Master

Aggiorna la password Master su tutti i personaggi già caricati in elenco, in un colpo solo.

Genera solo un hash senza toccare GitHub

Utile se preferisci incollare tu stesso l'hash a mano, o per un personaggio non ancora nell'elenco.


Nuovo personaggio

Per una scheda nuova, genera qui la password che vuoi dargli, e passa a Claude il file di partenza insieme a quell'hash: lo inserisce lui al posto giusto nel nuovo file. Una volta caricato su GitHub, ricarica l'elenco qui sopra per poterlo gestire.
